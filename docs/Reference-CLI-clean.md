# Command Reference: `beru clean`

The `beru clean` command cleans up local build artifacts and generated CMake files in the current project, returning it to a pristine state.

---

## 1. Usage Synopsis

```bash
beru clean
```

---

## 2. Detailed Description

When working on a C++ project, build artifacts generated by CMake and the compiler accumulate in your local project directory.

Executing `beru clean` performs the following operations in the current working directory:

1. **Build Artifact Removal:** Recursively deletes the `build/` directory containing all object files (`.o`, `.obj`), intermediate CMake cache files, and compiled binaries.
2. **Toolchain Cleanup:** Removes the auto-generated `beru-toolchain.cmake` file.
3. **Override Rules Cleanup:** Removes any temporary `beru-override.cmake` files generated during fast syntax checks (`beru check`).

Unlike `beru cache clean` (which operates on the global `~/.beru/cache/` directory), `beru clean` strictly affects only the local project in the current working directory.

---

## 3. Examples

**Resetting the local project build artifacts:**
```bash
$ beru clean
Cleaned project
```

**Running when nothing needs cleaning:**
```bash
$ beru clean
Skipped Nothing to clean
```
